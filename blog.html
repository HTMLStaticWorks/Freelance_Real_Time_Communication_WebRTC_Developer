WebRTC Glossary

SFU

Selective Forwarding Unit. Routes media streams without altering them, optimizing for CPU load.

MCU

Multipoint Control Unit. Mixes multiple streams into a single layout. Highly CPU intensive.

STUN

Session Traversal Utilities for NAT. Helps peers discover their public IP addresses.

TURN

Traversal Using Relays around NAT. Relays media when P2P connections completely fail.

ICE

Interactive Connectivity Establishment. The framework that gathers STUN/TURN candidates.

Simulcast

Sending multiple resolutions of the same video stream so the SFU can route appropriately.

SVC

Scalable Video Coding. A single stream layered with temporal and spatial dependencies.

DTLS

Datagram Transport Layer Security. Encrypts data over UDP streams automatically.
