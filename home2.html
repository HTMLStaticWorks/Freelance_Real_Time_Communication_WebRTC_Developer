Built for Developers

Integrate my ultra-low latency infrastructure into your application with just a few lines of code using the heavily typed SDKs.

initialize_sfu.ts 
import { RtcForgeClient } from '@rtcforge/sdk';

// Initialize Transport
const client = new RtcForgeClient({
    apiKey: 'sk_live_x8f92j...',
    region: 'auto-route'
});

await client.connect();

// Publish local media stream
const stream = await navigator.mediaDevices.getUserMedia({ video: true });
await client.publish(stream, { simulcast: true });
